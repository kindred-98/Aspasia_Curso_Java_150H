Ejercicio 1 - Datos personales

Crea tres variables llamadas nombre, edad y ciudad. Asigna un valor a cada variable. Muestra los tres datos en la página utilizando document.write(). Nombre: Laura / Edad: 25 / Ciudad: Gijón

Pistas

  • Una variable se declara con var nombre = valor;.
  • Los textos van entre comillas: "Laura".
  • Los números van sin comillas: 25, para poder operar con ellos.
  • Para unir texto y variable usamos el signo +.

Recordatorio

Sintaxis

var nombre = "Laura";

Texto o número

  • "25" es texto: no se puede sumar.
  • 25 es número: sí se puede sumar.
  • Las comillas cambian todo.

Unir con +

"Nombre: " + nombre produce Nombre: Laura.
