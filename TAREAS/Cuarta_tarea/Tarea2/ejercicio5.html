Ejercicio 5 - Compra completa

Variables: Portátil, 650 EUR, 2 unidades, 10 % de descuento y 15 EUR de envío. Calcula subtotal, descuento aplicado, precio después del descuento y precio final. Usa etiquetas HTML dentro de document.write() para organizar el resumen en varias líneas: TOTAL: 1185 EUR

Pistas

  • Es el ejercicio 4 con una variable más: los gastos de envío.
  • El total final se calcula sumando el envío después del descuento.
  • Dentro de document.write() puedes escribir <h4> y <strong>.
  • Una variable por línea de cálculo, para no liarte.

Recordatorio

Los 4 pasos del cálculo

  • 1. Subtotal = precio x unidades
  • 2. Descuento = subtotal x % / 100
  • 3. Precio con descuento = subtotal - descuento
  • 4. Total = precio con descuento + envío

HTML en el write()

Podemos escribir etiquetas dentro del texto: document.write("<strong>TOTAL: 1185 EUR</strong>").

Ojo

El envío se suma después del descuento. Si lo sumaras antes, el resultado sería distinto.
