Enunciados

Ejercicio 1 - Datos personales

Crea tres variables llamadas nombre, edad y ciudad. Asigna un valor a cada variable. Muestra los tres datos en la página utilizando document.write(). Nombre: Laura / Edad: 25 / Ciudad: Gijón

Ejercicio 2 - Datos de un producto

Crea las variables producto, precio y cantidad. Crea una nueva variable total que multiplique el precio por la cantidad y muestra todos los datos con document.write(). Producto: Teclado / Precio: 30 EUR / Cantidad: 2 / Total: 60 EUR

Ejercicio 3 - Cálculo de edad

Crea nombre, anioNacimiento, anioActual (2026) y una variable edad que reste el año de nacimiento al año actual. Muestra una frase completa con document.write(). Ana nació en 1990 y tiene aproximadamente 36 años.

Ejercicio 4 - Precio con descuento

Producto Monitor con precio de 200 EUR y descuento del 15 %. Guarda el dinero descontado en una variable y calcula el precio final. Muestra todo con document.write(): Precio final: 170 EUR

Ejercicio 5 - Compra completa

Variables: Portátil, 650 EUR, 2 unidades, 10 % de descuento y 15 EUR de envío. Calcula subtotal, descuento aplicado, precio después del descuento y precio final. Usa etiquetas HTML dentro de document.write() para organizar el resumen en varias líneas: TOTAL: 1185 EUR

Recordatorio

Declarar una variable

Con var nombre = valor; guardamos un dato que podremos usar en cualquier parte del script.

Tipos de datos

  • Cadena de texto: "Laura" (entre comillas)
  • Número: 25 (sin comillas, permite operar)

Operadores

+ suma, - resta, * multiplica y / divide.
