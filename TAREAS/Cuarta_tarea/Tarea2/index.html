Resumen de lo que debemos hacer

Vamos a practicar variables en JavaScript y a mostrarlas en la página con document.write(). Cada ejercicio pide declarar una o varias variables, hacer algún cálculo con ellas y escribir el resultado en la propia página.

Cada ejercicio está en su propia página HTML. El enunciado completo está escrito en esa página y debajo aparece el código JavaScript ya resuelto, de forma que al abrir la página se ve directamente el resultado.

Las 3 cosas que hay que aprender

  • Declarar una variable con var nombre = valor;.
  • Distinguir texto ("Laura") de número (25).
  • Usar document.write() para mostrar el resultado.

Los 5 ejercicios

Ejercicio 1 - Datos personales

Declara nombre, edad y ciudad, y muéstralos: Nombre: Laura / Edad: 25 / Ciudad: Gijón.

Qué se practica: declarar variables y mostrarlas.

Ejercicio 2 - Datos de un producto

Declara producto, precio y cantidad, y calcula el total multiplicando: Total: 60 EUR.

Qué se practica: la primera operación con *.

Abrir ejercicio 2

Ejercicio 3 - Cálculo de edad

Calcula la edad restando el año de nacimiento al año actual: Ana nació en 1990 y tiene aproximadamente 36 años.

Qué se practica: la operación - dentro de una frase.

Abrir ejercicio 3

Ejercicio 4 - Precio con descuento

Aplica un 15 % de descuento sobre un producto de 200 EUR: Precio final: 170 EUR.

Qué se practica: porcentajes con / y -.

Abrir ejercicio 4

Ejercicio 5 - Compra completa

Compra completa con subtotal, descuento y envío, ordenada en varias líneas con etiquetas HTML: TOTAL: 1185 EUR.

Qué se practica: muchas variables juntas y HTML en el write().

Abrir ejercicio 5

Recordatorio

Declarar una variable

Con var nombre = valor; guardamos un dato que podremos usar en cualquier parte del script.

Tipos de datos

  • Cadena de texto: "Laura" (entre comillas).
  • Número: 25 (sin comillas, permite operar).

Operadores

+ suma, - resta, * multiplica y / divide.

document.write()

Escribe texto dentro de la página. Solo funciona mientras el navegador está leyendo el HTML, por eso el <script> va dentro de la zona de resultados.
