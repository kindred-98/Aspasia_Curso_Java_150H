Resumen de lo que debemos hacer

Vamos a practicar funciones en JavaScript. Cada ejercicio pide crear una función con un nombre concreto, y esa función tiene que mostrar su resultado en la propia página usando document.write().

Cada ejercicio está en su propia página HTML. El enunciado completo está escrito en esa página y debajo aparece el código JavaScript ya resuelto, de forma que al abrir la página se ve directamente el resultado.

Las 4 cosas que hay que aprender

  • Declarar una función con function y darle un nombre.
  • Recibir datos con parámetros y devolvirlos con return.
  • Pasar los datos al ejecutarla con argumentos.
  • Mostrar el resultado con document.write().

Los 5 ejercicios

Ejercicio 1 - Saludo

Crea saludar(), una función sin parámetros que muestre Hola, bienvenido a JavaScript.

Qué se practica: declarar una función y llamarla.

Abrir ejercicio 1

Ejercicio 2 - Mostrar un nombre

Crea mostrarNombre(nombre), que recibe un nombre por parámetro y saluda: Hola Patricia.

Qué se practica: una función con 1 parámetro.

Abrir ejercicio 2

Ejercicio 3 - Sumar dos números

Crea sumar(numero1, numero2) que reciba dos números, los sume y muestre La suma es: 15.

Qué se practica: una función con 2 parámetros.

Abrir ejercicio 3

Ejercicio 4 - Calcular el doble

Crea doble(numero) que devuelva el doble con return: El doble de 8 es 16.

Qué se practica: el primer uso de return.

Abrir ejercicio 4

Ejercicio 5 - Calcular precio total

Crea calcularTotal(precio, cantidad) que multiplique y devuelva el total: Precio: 20 € / Cantidad: 3 / Total: 60 €.

Qué se practica: return con 2 parámetros.

Abrir ejercicio 5

Recordatorio

¿Qué es una función?

Bloque de código con nombre que se puede ejecutar tantas veces como necesitemos con nombre().

Estructura

function nombre(parametros) { ... }

Parámetro y argumento

  • Parámetro: el hueco que recibe la función en su definición.
  • Argumento: el valor real que le pasamos al llamarla.

return

Devuelve un valor al lugar donde se llamó la función. Sin return la función devuelve undefined.

document.write()

Escribe texto dentro de la página. Solo funciona mientras el navegador está leyendo el HTML, por eso el <script> va dentro de la zona de resultados.
