Ejercicio 3 - Sumar dos números

Crea una función llamada sumar(numero1, numero2). La función debe recibir dos números, sumarlos y mostrar el resultado con document.write(): La suma es: 15.

Pistas

  • Los dos parámetros se separan con una coma: sumar(numero1, numero2).
  • El orden importa: el primer argumento entra en el primer parámetro.
  • Para sumar se usa +, pero entre dos números.
  • Guarda el cálculo en una variable antes de mostrarlo.

Recordatorio

Dos parámetros

function sumar(numero1, numero2) { ... }

Orden de los argumentos

  • sumar(7, 8) → numero1 vale 7.
  • En esa misma llamada, numero2 vale 8.
  • El orden de los parámetros y el de los argumentos debe coincidir.

+ o concatenar

+ suma si los dos lados son números y junta textos si alguno es una cadena.

Resultado

7 + 8 = 15, que es el resultado que pide el enunciado.
