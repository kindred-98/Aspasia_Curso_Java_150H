Ejercicio 5 - Calcular precio total

Crea una función llamada calcularTotal(precio, cantidad). La función debe multiplicar el precio por la cantidad y devolver el resultado utilizando return. Después, guarda el resultado en una variable y muestra con document.write() el precio, la cantidad y el total: Precio: 20 € / Cantidad: 3 / Total: 60 €.

Pistas

  • Para multiplicar se usa *: 20 * 3 = 60.
  • La función solo calcula y devuelve; de mostrar se encarga quien la llama.
  • El símbolo del euro se escribe con la entidad &euro;.
  • Este ejercicio junta los dos anteriores: 2 parámetros y return.

Recordatorio

Flujo del ejercicio

  • 1. Declaramos calcularTotal(precio, cantidad).
  • 2. Dentro multiplicamos y hacemos return.
  • 3. Fuera, declaramos las variables precio y cantidad.
  • 4. Llamamos y guardamos: var total = calcularTotal(precio, cantidad);
  • 5. Mostramos las tres cosas con document.write().

Por qué return

Con return la función se puede usar para cualquier producto: la misma función sirve para 20 x 3, para 5 x 10 o para 99,90 x 2.
