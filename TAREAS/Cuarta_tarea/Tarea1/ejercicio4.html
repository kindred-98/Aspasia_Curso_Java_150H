Ejercicio 4 - Calcular el doble

Crea una función llamada doble(numero). La función debe recibir un número y devolver su doble utilizando return. Después, guarda el resultado en una variable y muéstralo con document.write(): El doble de 8 es 16.

Pistas

  • return devuelve el valor al lugar donde llamaste la función.
  • Para multiplicar se usa *.
  • Guarda el resultado de la función en una variable para poder mostrarlo.
  • Sin return, la función devolvería undefined.

Recordatorio

Qué hace return

Envía el valor de vuelta a quien llamó a la función y detiene la ejecución en esa línea.

Estructura

function doble(numero) {
  return numero * 2;
}

Diferencia clave

  • En el ejercicio 3 la función pintaba el resultado con document.write().
  • Aquí la función devuelve el resultado y quien la llama lo muestra.
  • Una función con return se puede reutilizar en muchos sitios.
