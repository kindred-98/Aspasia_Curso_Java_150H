Ejercicio 4 - Variables y tipos de dato

Crea una variable para cada uno de los siguientes tipos de dato:

  • Guarda el nombre de una persona.
  • Guarda su edad.
  • Guarda su altura en decimales.
  • Indica si tiene carnet de conducir.
  • Crea una variable sin asignarle ningún valor.
  • Crea una variable cuyo valor sea null.
  • Guarda en una variable tres lenguajes de programación.
  • Guarda los datos de una persona: nombre y edad.
  • Muestra los datos en la consola.
  • Utiliza typeof para comprobar el tipo de cada variable.

Recordatorio

typeof devuelve

  • "string" para el texto
  • "number" para los números
  • "boolean" para true/false
  • "undefined" si no tiene valor
  • "object" para arrays, objetos y… null

El caso de null

typeof null devuelve "object". Es un error antiguo de JavaScript que se conserva por compatibilidad con código viejo.

Array

["HTML", "CSS"] guarda varios valores. Las posiciones empiezan en cero: el primer elemento es lenguajes[0], nunca [1].

Objeto

Agrupa datos que pertenecen a lo mismo. Cada dato es una propiedad: nombre es la clave y "Ana" el valor.
