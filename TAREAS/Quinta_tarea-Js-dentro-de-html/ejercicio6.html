Ejercicio 6 - Saludo

Crea una función llamada saludar() que muestre en la página el siguiente mensaje utilizando document.write(): Hola, bienvenido a JavaScript. Después, llama a la función para comprobar que funciona.

Pistas

  • Una función se escribe function nombre() { ... }.
  • Los paréntesis van vacíos porque no recibe ningún dato.
  • Para ejecutarla escribes saludar();.
  • Las llaves { } marcan dónde empieza y acaba la función.

Recordatorio

Sintaxis

function saludar() {
  document.write("...");
}

Partes

  • function: palabra clave que declara la función.
  • saludar: el nombre que le damos.
  • (): los parámetros. Aquí no hay ninguno.
  • { }: el bloque de código que se ejecuta.

Ojo

Si declaras la función pero no la llamas con saludar();, no se ve nada en la página.
