Ejercicio 1 - Variable edad

Crea una variable llamada edad y asígnale tu edad. Muestra el resultado a través de la consola y luego actualiza el valor de edad y vuelve a mostrar el valor.

Pistas

  • let declara una variable cuyo valor puede cambiar.
  • Para cambiar el valor se escribe solo el nombre: edad = 45;, sin let.
  • console.log() escribe en la consola del navegador (F12 → Console).
  • document.write() escribe dentro de la página.

Recordatorio

Declarar

let edad = 45;

Cambiar el valor

edad = 46;
Sin let. Si lo pones otra vez, JavaScript da error.

Ver el resultado

  • En la consola: console.log(edad);
  • En la página: document.write(edad);
