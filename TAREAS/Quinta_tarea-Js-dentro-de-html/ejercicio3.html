Ejercicio 3 - Constante PI

Crea una constante llamada PI y asígnale el valor de 3.14159. Luego intenta cambiar el valor de la misma y observa el resultado en la consola.

Pistas

  • const declara un valor que no se puede reasignar.
  • Por convención las constantes se escriben en mayúsculas: PI, MAXIMO.
  • Si intentas reasignarla, la consola da el error TypeError: Assignment to constant variable.
  • Ese error para el JavaScript: lo que venga después no se ejecuta.

Recordatorio

let frente a const

  • let edad = 45; → se puede cambiar.
  • const PI = 3.14159; → no se puede cambiar.

Por qué usar const

Deja claro a quien lea el código que ese valor no va a cambiar. Es lo ideal para valores fijos como PI o un IVA.

Importante

El error de reasignar un const detiene el JavaScript entero. Por eso en este ejercicio la línea está comentada: si la quitas los comentarios, verás el error en la consola y el resto de la página se quedará sin pintar.
