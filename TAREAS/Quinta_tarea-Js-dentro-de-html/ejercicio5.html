Ejercicio 5 - Ámbito de una variable

Declara una variable dentro de una función y trata de acceder a ella fuera de la función.

Pistas

  • Una variable creada dentro de una función es local: solo existe dentro de ella.
  • Una variable creada fuera de cualquier función es global: existe en toda la página.
  • Intentar leer una variable local desde fuera da el error ReferenceError: mensaje is not defined.
  • Ese error para el JavaScript, así que vuelve a dejarlo comentado.

Recordatorio

Ámbito (scope)

Es el sitio donde existe una variable. La palabra scope significa alcance.

Local

Creada dentro de una función con let. Desaparece cuando la función termina.

Global

Creada fuera de cualquier función. Se puede usar en cualquier parte de la página, aunque es mejor evitarla.

Buena práctica

Declara las variables dentro de las funciones que las usan: así se evita que unas funciones pisen los datos de otras.
