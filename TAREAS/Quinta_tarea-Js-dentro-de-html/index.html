Resumen de lo que debemos hacer

Vamos a practicar variables y funciones en JavaScript. Cada ejercicio pide declarar variables, ver de qué tipo son y, en el último caso, ver hasta dónde llega una variable.

El enunciado de cada ejercicio está en su propia página. Esta vez el JavaScript va escrito dentro del propio HTML, en una etiqueta <script>.

Las 4 cosas que hay que aprender

  • Declarar una variable con let o con const.
  • Distinguir los tipos: texto, número, booleano, array y objeto.
  • Comprobar el tipo de una variable con typeof.
  • Diferir una variable local de una global (ámbito o scope).

Dónde se ve el resultado

Estos ejercicios usan console.log(), así que el resultado aparece en la consola del navegador (púlsalo con F12 y entra en la pestaña Console). Para verlo también dentro de la página, cada ejercicio escribe su resultado con document.write() en la zona de resultados.

Los 5 ejercicios

Ejercicio 1 - Variable edad

Crea una variable edad, muéstrala, cambia su valor y vuelve a mostrarla.

Qué se practica: let y reasignar el valor.

Ejercicio 2 - Variables con tipos de dato

Ejercicio 3 - Constante PI

Ejercicio 4 - Variables y tipos de dato

Crea una variable de cada tipo: texto, número entero, decimal, booleano, sin definir, null, un array y un objeto. Comprueba cada una con typeof.

Qué se practica: typeof, null y undefined.

Abrir ejercicio 4

Ejercicio 5 - Ámbito de una variable

Declara una variable dentro de una función e intenta usarla fuera de ella.

Qué se practica: variables locales y globales (scope).

Abrir ejercicio 5

Recordatorio

Declarar una variable

let edad = 45; se puede cambiar después. const PI = 3.14159; no.

Tipos de dato

  • "texto" es string: siempre entre comillas.
  • 25 es number: con o sin decimales.
  • true es boolean: solo true o false.
  • undefined: declarada pero sin valor.
  • null: vacía a propósito.
  • ["a", "b"] es un array.
  • { } es un objeto.

typeof

Devuelve el tipo de una variable como texto. Ojo: typeof null devuelve "object", es un error antiguo de JavaScript.

Ámbito (scope)

Una variable creada dentro de una función con let solo existe dentro de ella. Fuera daría error is not defined.
