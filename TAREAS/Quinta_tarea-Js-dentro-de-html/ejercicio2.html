Ejercicio 2 - Variables con tipos de dato

Crea tres variables: esEstudiante (boleano), promedio (número con decimal) y apellido (cadena de texto o string). Muestra el resultado en la consola.

Pistas

  • Un booleano solo puede ser true o false, sin comillas.
  • Un número va sin comillas: 8.5. Con comillas sería texto.
  • Un texto va siempre entre comillas.
  • console.log() puede mostrar varios valores en una sola llamada, separados por comas.

Recordatorio

BOOLEAN (booleano)

true o false. Sirve para responder sí o no: "¿tienes carnet? true".

NUMBER (número)

Con o sin decimales. En JavaScript no hay int ni double: hay un único tipo number.

STRING (texto)

Entre comillas, simples 'Hola' o dobles "Hola".

Ojo

"8.5" es texto y 8.5 es número. Con el texto no se puede sumar.
